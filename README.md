# Jarvis AI Voice Assistant

## About the Project
Jarvis AI Voice Assistant is a Python-based virtual assistant that uses voice commands to interact with users and perform tasks.

## Features
- Voice-based interaction
- Speech recognition
- Text-to-speech responses
- Graphical user interface
- Python-based application

## Technologies Used
- Python
- Speech Recognition
- Text-to-Speech
- Tkinter (GUI, if used by the application)

## Installation

1. Install Python on your computer.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Install the required libraries:

```bash
pip install -r jarvis_assistant/requirements.txt
```

## How to Run

Open Command Prompt in the main project folder and run:

```bash
python jarvis_assistant/main.py
```

## Project Structure

- `jarvis_assistant/main.py` – Main application entry point
- `jarvis_assistant/jarvis.py` – Assistant functionality
- `jarvis_assistant/gui.py` – Graphical user interface
- `jarvis_assistant/requirements.txt` – Required Python libraries
