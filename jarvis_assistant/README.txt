JARVIS - Personal Voice Assistant (Windows)

1. Install Python 3.12/3.13 (tick "Add to PATH").
2. In this folder:  python -m venv venv
                    venv\Scripts\activate
                    pip install -r requirements.txt
3. Open .env and set USER_NAME, BOT_NAME and your GEMINI_API_KEY.
4. python main.py
5. Press the ` (backtick) key, then speak. Alt+F4 to exit.
